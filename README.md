# 🪐 AlphaStarLaw - 中文法律大模型(律启星辰)
![logo](img/logo.png)
## 简介

&emsp;&emsp;欢迎来到 AlphaStarLaw。在法律这个严谨的领域，我们相信 AI 不应只是“聊天工具”，而应成为“专业助手”。我们始终坚信：**以技术普惠法治，以范式定义可信**。在 AlphaStarLaw 的研发中，通过构建多轮对话数据集和精细化参数调优，使模型在法律咨询、事实验证、阅读理解、关系抽取、文书生成等专业性显著提升。通过引入 **思维链(CoT)** 训练，成功强化了模型在复杂案情分析中的多步推理能力，实现了法律知识与生成逻辑的深度融合。

### 🛠 我们在做什么？

- 🔥 **法律大模型调优（Legal-Tuning-Cookbook）**：系统梳理和探索法律大模型从**增量预训练（Continue Pre-training）-> 全量指令微调（Full SFT）-> RLHF**的技术方案。深度研究如何平衡通用能力与法律专业知识，避免模型在学习法律知识后出现“**灾难性遗忘**”、“**指令退化**”、“**模式坍塌**”。

- 🔥 **可信训练范式（Credible-Tuning Paradigm）**：针对大模型的后训练方法和技术公开资料较少，我们针对法律场景对数据工程、训练范式进行原创性探索，**成功的探索出了大模型在各个阶段极具可移植性的训练范式**。输出一套标准化的**训练模组**，让“可信 AI”在不同垂直领域生根发芽。针对法律领域的特性，我们开发了一套 **“数据演进+证据增强+逻辑链约束+参数动态调优”** 的可信训练方式。通过在损失函数中引入法理逻辑一致性惩罚以及在训练过程中进行参数动态调优、训练数据学习难度动态评估，并结合法律知识图谱（KG）实时校验，从根源上抑制了模型的“**事实性幻觉**”、“**模式坍塌**”并显著提升模型性能。

- 🔥 **多维度性能评估（Multi-Dimensional Performance Benchmarking）**：多维度多数据集评测，自研模型在中文法律基准测试（如 LawBench、LexEval、CAIL）中的表现远超同参数规模的基线模型（Baseline）并且通用能力未发生衰减。在多项核心任务上，该模型展现出了跨越量级的竞争力，其实际表现甚至超越了参数量远大于自身的通用大模型。在案情分析、罪名预测及法律文书生成等关键任务上，其准确率与逻辑严密性甚至优于部分闭源商业模型。模型的模式坍塌现象得到了有效缓解，在生成任务上，重复性得到了显著降低。

- 🔥 **多轮对话数据集（Multi-Turn Dialogue Dataset）**：利用Self-Reflection Agent构建了多轮对话数据集以及深度推理分析数据集，并针对法律咨询场景进行了数据增强。通过引入思维链（CoT）训练，成功强化了模型在复杂案情分析中的多步推理能力，实现了法律知识与生成逻辑的深度融合。成功构建了**Evaluation -> Feedback -> Re-training**的自动化流水线（Pipeline）

### 结论

- 相较于基线模型和开源大模型，**自研法律大模型(alpha_star_law)在多项法律公开基准测试中均展现出显著的效果提升(详情参考评估结果)**。在法律知识问答、复杂案情深度解构、裁判路径演化预测及超长法律文本理解等核心维度，模型仍面临严峻挑战，后续会通过持续的算法迭代与垂直领域知识的深度融合来进一步优化。
- 成功探索出**可信训练范式（Credible-Tuning Paradigm）**，我们成功将训练范式运用到了不同的基线模型、行业领域以及不同的训练阶段，不仅取得了显著的效果提升而且训练范式极具可移植性。
- **法律大模型(alpha_star_law)** 在缓解指令退化、模式坍塌方面较基线模型表现更好。法律大模型(alpha_star_law)针对指令退化、模式坍塌仍有很大的优化空间，后续将持续的‘动态演进、不断迭代’。
- **法律大模型完成V2版本(8B)迭代，性能实现显著跃升**。在LawBench评测中，V2较基线提升24.5%（V1较基线提升5.8%）；在LexEval评测中，V2较基线提升23.3%（V1较基线提升18.5%），各项指标均呈加速增长态势且V2版本的各项指标均优于参数量更大的开源模型。[详细数据请参阅附件html 评估文档(下载后用浏览器打开)](./LegalKit-main/model_scores/自研法律大模型测试评估报告v2.html)。

### [LawBench](https://github.com/open-compass/LawBench) 数据集评测

LawBench经过精心设计，可对大语言模型的法律能力进行精确评估。 在设计测试任务时，我们模拟了司法认知的三个维度，并选择了20个任务来评估大模型的能力。数据集包括 20 个不同的任务，涵盖 3 个认知水平：
- 法律知识记忆：大语言模型能否记住必要的法律概念、术语、法条和事实。
- 法律知识理解：大语言模型能否理解法律文本中的实体、事件和关系，从而理解法律文本的意义和内涵。
- 法律知识应用：大语言模型能否正确利用其法律知识、对其进行推理从而解决下游应用中的现实法律任务。

### 如何评估模型的性能
我们在 [LegalKit](https://github.com/DavidMiao1127/LegalKit) 的基础上对评估脚本进行了深度优化，并提供了详细的日志，方便用户快速评估模型性能。为了方便对比不同模型的具体指标性能，我们提供了 **模型评估看板** 方便用户快速查看模型在不同任务上的具体性能。
#### 评估脚本

```bash

law-eval.shTIMESTAMP=$(date -d "+8 hours" +"%m%d_%H%M%S")
DATASET_NAME="LawBench"
# DATASET_NAME="LexEval"
MODEL_NAME="Qwen8B-off-policy-fintuned"

export CUDA_DEVICE_ORDER=PCI_BUS_ID
export NCCL_DEBUG=INFO

export CUDA_VISIBLE_DEVICES=0,1

# 
python legalkit/main.py \
  --models  ${MODEL_NAME} \
  --datasets ${DATASET_NAME} \
  --accelerator vllm \
  --max_tokens 4096 \
  --num_workers 1 \
  --tensor_parallel 2 \
  --batch_size 32 \
  --temperature 0.1 \
  --top_p 0.9 \
  2>&1 | tee ${DATASET_NAME}_${TIMESTAMP}.log

```
#### 模型评估看板

我们提供了一套可视化的模型评估工具，方便用户快速查看模型在不同任务上的具体性能。用户可以通过以下脚本访问模型评估看板：

1. 将评估结果保存到看板
